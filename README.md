# Ejercicios en Turbo Pascal

Programas básicos escritos en Turbo Pascal:

- `hola_mundo.pas`: muestra un mensaje de Hola Mundo.
- `operaciones.pas`: solicita dos números y calcula suma, resta, multiplicación y división.
- `calculadora_procedures.pas`: calculadora organizada mediante varios `procedure`.

## Compilación

Estos programas están pensados para Turbo Pascal clásico. Ábrelos en Turbo Pascal y ejecútalos con **Run > Run** o compílalos desde el entorno compatible que utilices.

> La división valida que el segundo número no sea cero antes de calcular el resultado.
